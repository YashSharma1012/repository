# Ponytail skills

Vendored from https://github.com/DietrichGebert/ponytail (commit 96608e0), MIT licensed (see PONYTAIL-LICENSE).

Claude Code loads these automatically in this repo. Invoke with `/ponytail [lite|full|ultra|off]`,
`/ponytail-review`, `/ponytail-audit`, `/ponytail-debt`, `/ponytail-gain`, `/ponytail-help`.

Only the skills are installed. The plugin's hooks (always-on mode, statusline) are not; for those,
install the full plugin: `/plugin marketplace add DietrichGebert/ponytail` then `/plugin install ponytail@ponytail`.
To update, re-copy `skills/*` from the upstream repo.
